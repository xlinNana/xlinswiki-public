## 总结
高质量的QTE基本上都会满足的点：

| **具备的特质** | **详解**                                                |
| --------- | ----------------------------------------------------- |
| 主次关系清晰    | 玩家控制的人一定会摆在更靠近镜头的位置，且占据更多的占比                          |
| 位置清晰      | QTE按键的提示位于屏幕中央或者需要交互的目标处                              |
| 目的明确      | QTE按键要按什么，往往和当前场景需要的操作是一致的，该闪避的时候不按攻击                 |
| 反馈明确      | QTE环节的开始、持续、结束都需要有与之对应的反馈，以强化玩家操作实感                   |
| 节奏对齐      | 当动作慢放时，QTE的限制时间应该和慢放时长保持一致。当QTE需要不限时长时，应当有与之相对的循环动画支持 |
| 边界清晰      | 在进入QTE前后需要有明确的镜头切换或运镜等形式告知（特指需要慢放或循环的QTE）             |
