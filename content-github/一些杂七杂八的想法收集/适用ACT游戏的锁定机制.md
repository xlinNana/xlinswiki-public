## 前言

```
在后续的学习中，我认为：明确的锁定规则＞模糊的锁定规则，特别是在高速的ACT环境中，战斗过程中分数是动态快速变化的，这时候需要有一个明确的主要规则帮助玩家建立低负担的认知，在游玩体验中，前几位的锁定命中率更为重要
这一版的锁定规则存在明显的一个问题是：在玩家的脑海里其实并不存在这样的一张热力图，过于相近且连续的计分规则实际上给玩家造成较高的认知负担，不够直观，eg：在《原神》的锁定规则中，距离是主要要素；在《鬼泣》中是输入方向；
基于主要规则再做细则区分，会比混用两个规则来的清晰明了

```


该锁定规则仅适用需要较高频率选择战斗单位的快节奏战斗游戏，结合《鬼泣5》与《HiFiRush》等游戏存在的问题提出试行的方案。
## 锁定规则

| 优先级 | 判断条件      | 影响范围及系数                        | 其他可能的方式                              | 存在的问题                |
| --- | --------- | ------------------------------ | ------------------------------------ | -------------------- |
| 1   | 索敌范围      | 目标处于索敌范围内1，否则为0                |                                      |                      |
| 2   | 屏幕中心点（特殊） | 技能存在该判定条件时为100,000，否则为0        |                                      |                      |
| 3*  | 敌人距离      | 目标距离玩家越近越高，范围为2000-10,000      |                                      | 距离与角色面朝方向的混用是否可行     |
| 4*  | 角色面朝方向    | 目标与角色面朝方向夹角越小越高，范围为2000-10,000 | 偏向30°内为10,000，60°内为5,000，大于60°为2,000 | 是否需要做一个角度/距离的梯度得分    |
| 5   | 上次攻击目标    | 目标为上次被攻击的单位为1,000，否则为0         |                                      |                      |
| 6   | 相机视野      | 在相机视野内为100， 否则为0               |                                      |                      |
| 7   | 输入方向      | 与输入方向夹角越小越高，范围为0-50            |                                      | 是否需要做一个角度的梯度得分       |
| 8   | 敌人危险度     | 基于敌人释放攻击动态调整危险度                |                                      | 少数情况下使用，当使用时优先级通常会很高 |
| 9   | 敌人优先级     | 目标怪物优先级数值                      |                                      |                      |

注：*号标记表示前后优先级相等

将各项判断条件得出的数值进行如下计算：索敌范围 * （其他各项相加）
锁定目标即为数值最大的目标
当存在多个目标得分相等时，优先攻击距离最近的单位

## 强锁机制
强锁锁定规则参考软锁，不会动态切换锁定目标
*锁定状态下玩家的所有攻击指向被锁定的单位，除玩家主动切换或解除锁定或被锁敌人死亡外，不会切换锁定目标
